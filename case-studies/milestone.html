Milestone - Edtech brand's mobile app offers gamified learning for kids to achieve financial independence.

Challenges

Milestone aims to teach children financial independence through a gamified experience. Bringing financial literacy to the APAC region for kids required solving several UX hurdles:

  • Engagement Gap: Finance is naturally unexciting for children. We had to turn "saving" into a "quest."
  • Dual User Base: Designing a playful, high-energy UI for kids while providing a secure, data-rich admin view for parents.
  • Concept Simplification: Translating banking concepts like interest, credit, and savings goals into visual metaphors children can grasp.
  • Trust & Security: Ensuring parents felt 100% in control of the spending limits and data.

Objectives

  • Gamify the Wallet: Implement a progress-based system where kids unlock "milestones" for hitting savings goals.
  • Total Visibility: Create a dashboard for parents to monitor, approve, and incentivize spending in real-time.
  • Build for APAC: Localize the visual language and currency handling for the specific cultural needs of the region.
